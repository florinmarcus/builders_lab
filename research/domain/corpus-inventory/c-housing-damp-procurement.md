## How to fetch versions

**legislation.gov.uk**
- Add `/data.xml` (or `/data.akn`, `/data.pdf`) to any URL. Example tested: `https://www.legislation.gov.uk/uksi/2025/1042/regulation/1/data.xml` (has `RestrictStartDate`).
- Original text: add `/made` (SIs) or `/enacted` (Acts). Made date is in `<ukm:Made Date=…>` in `/made/data.xml` (used for C01, C02, C14, C26, C28, C29, C35, C38).
- Point in time: add `/YYYY-MM-DD`. Tested: `https://www.legislation.gov.uk/ukpga/1985/70/section/11/2010-01-01/data.xml` returned 200. Primary legislation goes back to 1 Feb 1991 at most. SIs made from 2014 (and all from 2018) are revised; older SIs may only be "as made" (help page).
- Check the "Changes to legislation" / outstanding effects box each run. Editors take 4–8 weeks to apply changes (help page). SI 2026/1195 is a live example: made 13 Nov 2026, in force 30 Nov 2026, not yet in the revised text of SI 2025/1042.
- Drafts live under `/ukdsi/`; they link to the made SI once made.

**GOV.UK**
- Content API gives dates and change notes as JSON: `https://www.gov.uk/api/content/<path>`. Tested on `government/publications/awaabs-law-guidance-for-social-landlords`: returned first_published_at, public_updated_at and 4 change-history notes.
- GOV.UK keeps only the current text. Change notes say what changed, not the old text. For older text use the UK Government Web Archive (webarchive.nationalarchives.gov.uk). My test of its URL listing returned HTTP 405 to curl, so this is **unverified**; try through a browser or its CDX API.
- PDFs on assets.publishing.service.gov.uk get a new media ID when replaced; store the media URL and hash with each version.

**Housing Ombudsman, TrustMark, BSI, M3**: no versioning found. Store fetch date and hash; re-check by hand.
