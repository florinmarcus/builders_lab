# Research

Documents only, no code. Every fact needs a source in `sources/`.

- `domain/`: how these businesses work (jobs, quotes, materials, suppliers, regulations, paperwork).
- `pain-points/`: problems we found, who has them, how often, how they solve them today.
- `market/`: competitors, existing tools, pricing, the Romanian community (size, where, channels).
- `hosting-costs/`: cheapest hosting that can run our models. Dated price comparisons.
- `models/`: which models we can use, cost per call, Romanian language quality.
- `sources/`: links, documents and interview notes behind the claims.
