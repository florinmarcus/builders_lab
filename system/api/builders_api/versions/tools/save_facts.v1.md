Record what you read in ONE email from sync_inbox. Give: email_id; job (the job ref, e.g. ELM-22) if the email clearly belongs to one job, else leave it out; for each attachment its document_type (quote, acceptance, variation, invoice, application_for_payment, payment_notice, pay_less_notice, contract_particulars, rams, insurance_certificate, electrical_certificate, building_control_approval, building_control_completion, completion_photos, works_order, asbestos_survey, gas_capping_note, gas_safety_record, electrical_test, drawing_schedule, chat_export, order_confirmation, other) and dates (document_date, expires_on as YYYY-MM-DD); and the facts. Fact types: approval (client's own words approving a change), discussion (talked about, NOT approved), variation, quote_accepted, key_date, amount, asbestos_item (one per room or material, with the result exactly as written), survey_scope, certificate_pending, instruction, request, other. Every fact needs a short summary and a quote copied word for word from the email or the attachment (set attachment_id when the quote is from an attachment). The server rejects quotes it cannot find, unknown types and bad dates, and tells you why. Never record "no asbestos": record what the survey says for each sample and what it did not cover. Save an email with no facts (e.g. an order confirmation) by calling with an empty facts list, so it is not offered again.
